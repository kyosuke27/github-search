# GitHub ユーザー情報表示アプリ 仕様書

このドキュメントに、画面のUIと機能要件を整理していく。

## 目的

GitHubユーザー名を入力し、ユーザー情報とリポジトリ一覧を確認できるようにする。

## 画面構成

- ユーザー名入力欄
- 検索対象の選択欄
- ユーザー情報取得ボタン
- リポジトリ一覧取得ボタン
- 結果表示領域

## 機能要件

### ユーザー情報

- 入力されたGitHubユーザー名を使ってユーザー情報を取得する。
- ユーザー名、アカウント名、アバター、所在地、公開リポジトリ数を表示する。

### リポジトリ一覧

- 入力されたGitHubユーザー名を使ってリポジトリ一覧を取得する。
- リポジトリ名、説明、WebページへのURL、オーナー名を一覧表示する。

### エラー表示

- ユーザーが存在しない場合や通信に失敗した場合は、エラー内容を表示する。

## API

- `GET https://api.github.com/users/{userId}`
- `GET https://api.github.com/users/{userId}/repos`
